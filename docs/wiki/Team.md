## ✋ Add yourself

Adding your GitHub handle to this page is **your first open-source exercise**:

1. Open (or pick) the matching issue and create a branch, e.g. `docs/<issue-number>-add-<your-name>-to-team`
2. Edit [`docs/wiki/Team.md`](https://github.com/exceev-technology/rembo/blob/main/docs/wiki/Team.md) and replace *pending* with your handle
3. Commit `docs(wiki): add <your name> to team page`, push and open a pull request
4. Get a review from a teammate, then squash-merge

The full walkthrough is in [Git & PR Workflow](Git-and-PR-Workflow) and the [Learning Path](Learning-Path#2-git--github).
